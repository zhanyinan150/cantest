## 0 如何提问？ ​

如何提问？这是个大问题，可以参考<https://github.com/ryanhanwu/How-To-Ask-Questions-The-Smart-Way/blob/main/README-zh_CN.md>

> **提问前要先检查一下自己的硬件：**
> 
>   * [ ] TF卡是什么牌子的，哪里买的，发购买链接，我们只推荐在商城购买庐山派那个页面说明的TF卡。强烈不建议各位从pdd购买，即使是闪迪这种大牌子现在也有很多假货。来源不明的TF卡不建议使用。
>   * [ ] TF卡有没有插到位，插入时有没有清脆的卡扣咔哒一声。
>   * [ ] 庐山派正常上电，用户灯（RGB灯）会亮一下然后在两秒内熄灭，电源灯（PWR）红灯会保持常亮。 
>     * [ ] 如果用户灯有微亮，不能完全灭掉，那就和没有插入TF卡一个现象，此时庐山派会进入bootloader模式，你应该可以在设备管理器中看到新的设备。
>     * [ ] 如果用户灯不受控，可能固件烧录错误，或者TF卡不行。烧录的固件一定要是最新版本的。
>     * [ ] 如果电源灯一直不亮，有可能是主芯片K230已经坏了，庐山派的3.3V供电并不是上电即供电的，其被一个电子负载开关控制，该电子开关受控于K230的RTC引脚，当芯片可以正常工作时，OUT0会控制系统的3.3V正常上电。所以电源红灯不亮基本就是出大事了。
> 


别说什么刚刚还能用；什么都没干；睡了一觉起来就不能用了；拔插 一下就不能用了，这种话一说出来就和放了个p一样，毫无价值，徒增沟通成本。

要说清楚你之前的使用方式，供电方式，有没有外接了什么东西，任务管理里面有没有新设备出来，用的哪个例程。按照以下方式来提问：

> 我使用的是立创庐山派，当前使用的固件版本是xxx，编译时间是xxx，用的IDE是4.0.x。TF卡是在xx购买的，能确定TF卡是大品牌的正规销售途径，之前已经试过更换TF卡并重新烧录固件了。我用xxx方式来供电，电源红灯是否可以正常亮，用户RGB灯是否在上电时会亮以下然后在两秒内完全熄灭，电脑设备管理器是否有新的设备出来，截图发出来。是新的端口还是**K230 USB Boot Device** 。出现问题前，我做了如下操作，xxxx；当前开发板的状态是这样的，xxx；录视频发群里。用的例程是xxx，发群里。

**换一种表达方式**

为了高效准确地解决您的问题，请在提问时**避免提供模糊无效的信息** ，例如：

     * **录屏或视频** ：清晰地展示问题现象（包括硬件连接状态、指示灯状态、屏幕现象等）。请发到群里。

## 2 没法正常启动？ ​

可能的原因

  1. 卡不行，不兼容或者速度不够，建议用这个：<https://item.szlcsc.com/8422936.html> ， 我现在用的就是这个。
  2. 烧录的固件不对，一定是要.img后缀结尾，文件名里带"LCKFB"字样的。建议用最新的版本，请看快速入门文档里面的下载链接。
  3. 固件没有烧录好，看一下设备管理器里是不是有一个【K230 USB Boot Device】，有的话就是启动不成功进入了bootloader模式。
  4. 线不行，里面没有数据传输线（D+，D-），只能供电，或者线材质量太差。
  5. 电脑不行，供电不足或者用了HUB，要直连电脑USB口，不要通过其他设备转接。
  6. 开发板坏了，请联系交流群里的开发菌进行售后，但我们每块开发板出厂前都会上电测试，请重点怀疑以上问题。

## 5 摄像头安装后没对准？ ​

INFO

这是因为受限于板子尺寸，默认摄像头座（CSI2）无法居中放置，但是在实际使用中，我需要让摄像头居中，这就导致摄像头的安装位置和CSI2是不对齐的，这【不是】设计失误，本来就是这样设计的。

* * *

  1. 单庐山派+一路摄像头正常工作，从TYPE-C接口供电，一般是不会超过400mA，正常的电脑A口最高可以供电500mA。

**USB5V_IN+** ：是TYPE-C供电时的电源路径。

**PIN5V_OUT_IN+** ：是板子上的排针处的5V和那三个GH1.25-4Pin的座子的供电路径。

  * **推荐** 在连接IDE的时候使用。
  * **不推荐** 脱机供电时使用。



在运动中容易松动。

### 6.2 用外部5V来供电 ​

  * **只** 推荐用来临时使用，或者对外供电，不建议通过本章介绍的方案来对庐山派进行供电。

## 7 为什么只接 TXD、RXD、GND 三根线，开发板仍可能被串口工具烧坏？ ​

⚠️先说结论

**供电电压不等于 IO 信号电平。** 即使没有连接串口工具的 5V 供电脚，TXD / RXD 仍然是带电压的信号线。立创·庐山派K230-CanMV开发板和立创·庐山派Lite-K230D-CanMV开发板的 UART 信号只能使用 **3.3V 电平** ；ADC 引脚允许的最高输入电压更低，只有 **1.8V** 。

据售后统计，超过一半的庐山派 K230 主控损坏与外部工具 IO 电平过高有关。连接串口、单片机或其他外部设备前，请先确认其实际信号电平。

### 7.1 为什么不接 5V 供电仍会损坏开发板？ ​

很多用户认为串口通信只连接 TXD、RXD、GND，不连接 5V 供电就一定安全。这是一个常见误区。

  * 串口工具的 TXD 是输出信号。标准 TTL UART 在空闲状态下默认保持高电平，因此只要接上线，工具的 TXD 电压就会持续施加到开发板的 RXD 引脚上，与是否正在发送数据无关。
  * 市面上部分廉价 USB 转串口工具使用 5V TXD / RXD 电平，或者通过短接帽把 IO 电平切换到 5V。这样的信号不能直接连接庐山派。
  * 某些工具即使短接帽位于“3.3V”档，实测信号高电平仍可能达到约 3.8V，超过芯片 IO 的允许范围。
  * 过压不一定会让开发板立即失效。开发板可能短时间看起来正常，但输入保护结构会持续承受应力，最终造成 IO 或主控损坏。



重点检查工具 TXD

连接时通常是“串口工具 TXD → 开发板 RXD”。真正向开发板 IO 施加电压的是串口工具的 TXD，因此必须在接板之前测量工具 TXD 相对 GND 的空闲电平。

### 7.2 GH1.25-4P 串口座子上的 5V 只是供电脚 ​

庐山派提供 GH1.25-4P 带锁串口接口。座子的 `V` 脚是 5V 电源，**不代表 RXD / TXD 可以承受 5V 信号** 。

序号| 标识| 功能| 电气要求  
---|---|---|---  
1| V| 5V 输入/输出电源脚| 仅用于供电，不是串口信号  
2| R| RXD，串口接收| 3.3V UART 信号  
3| T| TXD，串口发送| 3.3V UART 信号  
4| G| GND| 与外部设备共地  
  
可以把 `V` 理解成电源插座，只负责送电；`R` 和 `T` 则是传递数据的通信线。电源脚标注 5V，只说明电源电压是 5V，不能据此推断通信线也是 5V 电平。

IMPORTANT

如果开发板已经通过 Type-C、12V 接口或其他方式供电，连接串口时不要再接 GH1.25-4P 的 `V` 脚，只连接 TXD、RXD、GND 即可。拔出 GH1.25 带锁插头时，应先压下卡扣，避免拉断线材或损坏座子。

### 7.3 如何在连接开发板前测量串口工具电平？ ​

测量时先不要连接开发板，只把 USB 转串口工具插入电脑：

  1. 将万用表切换到直流电压档，或者准备好示波器探头。
  2. 黑表笔或示波器地夹连接串口工具 GND。
  3. 红表笔或示波器探头连接串口工具 TXD。
  4. 不发送数据，直接读取 TXD 空闲状态下的电压。
  5. 只有确认高电平不超过 3.3V，才可以连接庐山派 UART。



DANGER

如果测得约 5V、3.8V，或者无法确认工具的真实信号电平，请停止连接。不要用开发板“试一下”，应更换可靠的 3.3V 串口工具，或者增加专用电平转换电路。

### 7.5 正确接线和工具选择 ​

确认串口工具使用 3.3V 信号电平后，按照交叉方式连接：

串口工具| 连接到庐山派| 说明  
---|---|---  
TXD| RXD| 工具发送，开发板接收  
RXD| TXD| 工具接收，开发板发送  
GND| GND| 双方必须共地  
5V / VCC| 默认不连接| 开发板已经单独供电时必须悬空  
  
  * 使用前确认的是 **TXD / RXD 信号电平** ，不是工具标注的 5V / 3.3V 供电输出档位。
  * 如果工具只能输出 5V 信号，必须增加可靠的电平转换电路，严禁直接连接庐山派 IO。
  * 不确定工具规格时，先测量再接线。不要仅凭短接帽颜色、丝印或商品描述判断。
  * 立创开发板推出的串口工具默认使用 3.3V 通信电平。不知道如何选择时，可以参考[立创开发板 CH340X USB 转 TTL 串口模块](https://lckfb.com/project/detail/lckfb-ch340x-usb-to-ttl-type-c?param=baseInfo&collection=e74002cdece14910b270b39aa06807e9)。



TIP

对硬件保持敬畏。不确定能否连接时，先测量或到官方交流群确认，再给开发板上电。花几分钟核对电平，通常比损坏主控后返修更省时间。
