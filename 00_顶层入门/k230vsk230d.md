## 核心差异速览

两者 AI 算力完全一致，差异集中在内存、接口和产品化取向上

💾

### 内存容量

这是两者最核心的差异。K230 搭载 1GB 外置 LPDDR4，适合大模型与多任务；Lite 使用 128MB SiP 集成内存，成本更低、供货更稳。

K230 · 1GB Lite · 128MB

🔌

### USB HOST

K230 标配 Type-A HOST 口，可外接 U 盘、USB 摄像头、网卡等设备。Lite 省去了这个接口，但换来了更小的 BOM。

有 Type-A 无 Type-A

🔊

### 音频输出

K230 提供 3.5mm 耳机接口用于调试；Lite 板载 HT6872 功放，可直驱 4Ω 喇叭，更适合产品化外放场景。

3.5mm 耳机 板载功放

📷

### 摄像头连接器

Lite 使用卡扣式连接器，比 K230 的插拔式更不容易被用户在频繁插拔中损坏，适合竞赛现场快速调试。

插拔式 卡扣式

🌀

### 风扇接口

Lite 额外提供 PWM 风扇接口，可直接驱动 5V 小功率负载（风扇、激光笔等），K230 无此功能。

无 有 · PWM

💰

### 成本与供货

Lite 采用 SiP 集成设计，BOM 更少，不受外置 DDR 涨价影响，成本可控且供货稳定，大赛批量采购更友好。

外置 DDR SiP 集成

### 同一 AI 算力，两种产品路径

#### 庐山派 K230 更适合

  * 较大模型、复杂视觉、多任务
  * 需要 USB HOST 外设扩展
  * 重开发调试、验证阶段
  * 需要大量 GPIO 外设驱动



#### 庐山派 Lite K230D 更适合

  * 轻量 AI、基础视觉、成本敏感
  * 大学生电赛 / 竞赛批量采购
  * 产品化外放（板载功放）
  * SiP 集成、BOM 少、供货稳

## 两个问题，帮你快速决策

选型时优先回答这两个关键问题

Q1：你的模型和系统是否需要超过 128MB 内存？

如果需要（大尺寸模型、Linux 多任务、复杂 pipeline），优先选 **庐山派 K230** 。  
如果 128MB 够用（轻量检测、分类、OCR、竞赛 Demo），**Lite** 的成本和稳定性优势更明显。

Q2：你是否需要 USB-A HOST 或大量外设扩展？

如果需要外接 U 盘、USB 摄像头、USB 网卡等设备，选 **庐山派 K230** 。  
如果不需要 USB HOST，**Lite** 的产品化设计（卡扣座、功放、风扇口）反而是加分项。
