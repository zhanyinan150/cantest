## 比赛脚本 k230_competition.py

### 工作流程

1. **Phase 1** - 豆子识别 (cam2 + best.kmodel，自动启动)
   - 识别 3 颗豆子（左->右），防抖 3 帧
   - 发送 `[0x02, 0x00, b1, b2, b3, 0, 0, XOR]` 给 STM32
   - 等待 STM32 应答 `0x06`，关闭 cam2

2. **Phase 2** - 正面数字识别 (cam1 + best.kmodel，STM32 触发)
   - 开 cam1 待命，等待 STM32 命令 `0x03`
   - K230 发 ACK `0x0A`，识别 3 个正面数字，防抖 3 帧
   - 发送 `[0x03, 0x00, n1, n2, n3, 0, 0, XOR]`，等待应答，关闭 cam1

3. **Phase 3** - 侧面数字+推理 (cam0 + best.kmodel，STM32 触发)
   - 开 cam0，发 ACK 确认就绪
   - 等待 STM32 命令 `0x01`，发 ACK
   - 识别侧面 1 个数字，推理第 5 个数字
   - 发送 `[0x01, 0x00, n1, n2, n3, n4, n5, XOR]`，等待应答，关闭 cam0

### 豆子编码

| 豆子 | 缩写 | 编码 |
|---|---|---|
| 绿豆 | g | 0x06 |
| 芸豆 | w | 0x07 |
| 黄豆 | y | 0x08 |

### 关键特性

- 单模型 `best.kmodel`（8 类），三阶段共用不切换
- NMS 非极大值抑制 + 坐标缩放校正
- OSD 图层复用（避免每帧分配内存导致黑屏）
- 摄像头切换时正确 stop/reset/del
- 所有帧 XOR 校验，每步通信都有 ACK 应答
