# K230 模型与摄像头说明

## 两个模型文件

| 模型文件 | 用途 | 使用场景 |
|---|---|---|
| `best1.kmodel` | 豆子识别 | 豆子场景（class g/y/w） |
| `best2.kmodel` | 数字识别 | 正面 + 侧面数字场景（class 1/2/3/4/5） |

两个模型**共用同一套 8 类标签**，只是训练数据侧重点不同：

```python
class_id   = ["1", "2", "3", "4", "5", "g", "w", "y"]
class_1_map = {
    "1": 0x01, "2": 0x02, "3": 0x03, "4": 0x04, "5": 0x05,
    "g": 0x06,  # 绿豆
    "y": 0x07,  # 黄豆
    "w": 0x08,  # 云豆
}
```

## 摄像头分配（两种方案）

### 方案 A：`k230_dual_model.py` / `k230_comm_test.py`（cam2=豆子, cam1=正面, cam0=侧面）

| 场景 | 命令码 | 摄像头 | 模型 | thing_num |
|---|---|---|---|---|
| 豆子 | 0x02 | **cam2** | best1 | 3 |
| 正面数字 | 0x03 | **cam1** | best2 / best1 | 5 |
| 侧面数字 | 0x01 | cam0 | best2 / best1 | 5 |

`k230_dual_model.py` 按场景切换 kmodel（豆子用 best1，数字用 best2）：
```python
SCENES = {
    0x02: (2, "/sdcard/best1.kmodel", 0x02, 3, "豆子"),
    0x03: (1, "/sdcard/best2.kmodel", 0x03, 5, "正面数字"),
    0x01: (0, "/sdcard/best2.kmodel", 0x01, 5, "侧面数字"),
}
```

`k230_comm_test.py` 只用 best1，摄像头分配同方案 A。

### 方案 B：`k230_10s_switch.py`（单模型 best1，cam1/cam2 与方案 A 对调）

| 场景 | 命令码 | 摄像头 | 模型 | thing_num |
|---|---|---|---|---|
| 豆子 | 0x02 | **cam1** | best1 | 3 |
| 正面数字 | 0x03 | **cam2** | best1 | 5 |
| 侧面数字 | 0x01 | cam0 | best1 | 5 |

```python
SCENES = [
    (2, 0x03, 5),   # 正面数字：cam2
    (0, 0x01, 5),   # 侧面数字：cam0
    (1, 0x02, 3),   # 豆子：cam1
]
```

### ⚠ 两种方案的区别

- **摄像头 1 和 2 对调了**：方案 A 中豆子用 cam2、正面用 cam1；方案 B 中豆子用 cam1、正面用 cam2
- 方案 A 用两个模型（best1 专攻豆子，best2 专攻数字），方案 B 只用 best1 跑全部
- 侧面数字两个方案都用 cam0，一致
- **实际硬件接线以方案 A 为准**（cam2=豆子, cam1=正面, cam0=侧面）

## 各脚本使用的模型

| 脚本 | 模型 | 摄像头数 | 摄像头方案 |
|---|---|---|---|
| `k230_dual_model.py` | best1 + best2 | 3（cam0/1/2） | A（cam2=豆,cam1=正,cam0=侧） |
| `k230_comm_test.py` | best1 | 3（cam0/1/2） | A（cam2=豆,cam1=正,cam0=侧） |
| `k230_10s_switch.py` | best1 | 3（cam0/1/2） | B（cam1=豆,cam2=正,cam0=侧） |
| `k230_direct_recognize.py` | best1 | 3（cam0/1/2） | B |
| `k230_version1.1.1.py` | best1 | 3（cam0/1/2） | B |
| `k230_version1.1.2_fixed.py` | best1 | 3（cam0/1/2） | B |
| `k230_cam2_only.py` | best1 | 1（cam0） | - |

> 注：`k230_version1.1.2_fixed.py` 的类名是 `"one","two",...,"greenbean",...`，与其他脚本不同，可能和 best1 模型不匹配，使用前需确认。

## 模型文件路径

所有脚本默认从 SD 卡加载：
- `/sdcard/best1.kmodel`
- `/sdcard/best2.kmodel`

单模型脚本里 `kmodel_path` 写的是 `/sdcard/best.kmodel`，实际需要改成 `best1.kmodel` 或 `best2.kmodel`。
