# K230 比赛视觉系统 - 通讯协议与工作流程

## 文件

| 文件 | 说明 |
|------|------|
| `view/k230_competition.py` | K230 端比赛主程序 |
| `modules/k230/K230.c` | STM32 端通讯驱动 |
| `modules/k230/K230.h` | STM32 端通讯接口定义 |

## 硬件连接

| K230 | STM32 | 说明 |
|------|-------|------|
| UART3 TX (Pin 50) | USART3 RX (PB11) | K230 -> STM32 |
| UART3 RX (Pin 51) | USART3 TX (PB10) | STM32 -> K230 |

- 波特率: 115200, 8N1
- 帧格式: 8 字节定长帧, byte[7] = XOR(byte[0..6])

## 模型与摄像头

- **单模型**: `bestm.kmodel`（8 类: `1, 2, 3, 4, 5, g, w, y`），三个阶段共用，不切换模型
- 数字类别索引 0-4，豆子类别索引 5-7

| 阶段 | 摄像头 ID | 识别目标 | 过滤类别索引 |
|------|-----------|----------|-------------|
| Phase 1 | cam 2 | 3 颗豆子（左->右） | 5-7 (g, w, y) |
| Phase 2 | cam 1 | 正面 3 个数字（左->右） | 0-4 (1-5) |
| Phase 3 | cam 0 | 侧面 1 个数字 | 0-4 (1-5) |

## 编码定义

### 豆子编码

| 豆子 | 缩写 | 编码 |
|------|------|------|
| 绿豆 | g | 0x06 |
| 芸豆 | w | 0x07 |
| 黄豆 | y | 0x08 |

### 数字编码

| 数字 | 编码 |
|------|------|
| 1 | 0x01 |
| 2 | 0x02 |
| 3 | 0x03 |
| 4 | 0x04 |
| 5 | 0x05 |

## 帧类型定义

### STM32 -> K230

| byte[0] | byte[1] | 含义 |
|---------|---------|------|
| 0x02 | 0x01 | 启动豆子识别（备用，K230 自动启动 Phase 1） |
| 0x03 | 0x01 | 启动正面数字识别 |
| 0x01 | 0x01 | 启动侧面数字识别 |
| 0x06 | 0x00 | 应答/关闭当前摄像头 |

### K230 -> STM32

| byte[0] | byte[1] | byte[2..6] | 含义 |
|---------|---------|------------|------|
| 0x02 | 0x00 | b1, b2, b3, 0x00, 0x00 | 豆子颜色帧（左->右） |
| 0x03 | 0x00 | n1, n2, n3, 0x00, 0x00 | 正面数字帧（左->右） |
| 0x01 | 0x00 | n1, n2, n3, n4, n5 | 完整 5 数字帧（左->右） |
| 0x0A | 0x00 | 0x00 × 5 | K230 应答帧 |

> 所有帧 byte[7] = byte[0] ^ byte[1] ^ ... ^ byte[6]

## 完整工作流程

### Phase 1: 豆子识别（K230 自动启动）

```
K230                          STM32
  |                              |
  | [自动] cam2 + bestm.kmodel   |
  | 识别 3 颗豆子（左->右）        |
  | 防抖 3 帧确认                 |
  |                              |
  |---- 0x02 00 b1 b2 b3 00 00 XOR ---->|
  |                              |  bean_flag=1, bean_locked=1
  |                              |
  |<--- 0x06 00 00 00 00 00 00 XOR ----|
  |                              |
  | 关闭 cam2                    |
  |                              |
```

### Phase 2: 正面数字识别（STM32 触发）

```
K230                          STM32
  |                              |
  | [自动] 开启 cam1 待命显示     |
  |                              |
  |                              |  到达位置
  |<--- 0x03 01 00 00 00 00 00 XOR ----|
  |                              |
  |---- 0x0A 00 00 00 00 00 00 XOR ---->|  K230 应答
  |                              |
  | 识别正面 3 个数字（左->右）    |
  | 防抖 3 帧确认                 |
  |                              |
  |---- 0x03 00 n1 n2 n3 00 00 XOR ---->|  front_number_flag=1
  |                              |
  |                              |  到达下一个位置
  |<--- 0x06 00 00 00 00 00 00 XOR ----|
  |                              |
  | 关闭 cam1                    |
  |                              |
```

### Phase 3: 侧面数字识别 + 推理第 5 个数字

```
K230                          STM32
  |                              |
  | [自动] 开启 cam0             |
  |                              |
  |---- 0x0A 00 00 00 00 00 00 XOR ---->|  确认 cam0 就绪
  |                              |
  |                              |  到达新位置
  |<--- 0x01 01 00 00 00 00 00 XOR ----|
  |                              |
  |---- 0x0A 00 00 00 00 00 00 XOR ---->|  K230 应答
  |                              |
  | 识别侧面 1 个数字            |
  | 防抖 3 帧确认                 |
  |                              |
  | 推理第 5 个数字:              |
  |   已知 4 个 = 3正面 + 1侧面   |
  |   第 5 个 = {1,2,3,4,5} - 已知|
  |                              |
  | 组合 5 个数字（左->右）:       |
  |   [侧面, 正面1, 正面2, 正面3, 推理] |
  |                              |
  |---- 0x01 00 n1 n2 n3 n4 n5 XOR ---->|  full_number_flag=1, count++
  |                              |
  |<--- 0x06 00 00 00 00 00 00 XOR ----|
  |                              |
  | 关闭 cam0, 释放模型          |
  |                              |
```

## 第 5 个数字推理逻辑

1. 已知 4 个数字: 3 个正面数字 + 1 个侧面数字
2. 候选集: {0x01, 0x02, 0x03, 0x04, 0x05}
3. 从候选集中去除已知 4 个，剩余即为第 5 个
4. 5 个数字排列顺序（左->右）: `[侧面, 正面1, 正面2, 正面3, 推理第5]`

## 防抖机制

- 每个识别阶段要求连续 **3 帧** 检测结果相同才确认
- 豆子: 3 颗豆子颜色完全一致 × 3 帧
- 正面数字: 3 个数字完全一致 × 3 帧
- 侧面数字: 同一数字 × 3 帧

## STM32 端使用要点

### 现有代码兼容性

STM32 端 `K230.c` 已支持解析以下帧:
- `0x02` -> `bean_color[3]`, `bean_flag=1`
- `0x03` -> `front_number[3]`, `front_number_flag=1`
- `0x01` -> `number_position[5]`, `full_number_flag=1`

`0x0A` (K230 ACK) 帧会被 STM32 忽略（XOR 校验通过但 byte[0] 无匹配 case），如需等待 ACK 可添加处理。

### 豆子颜色宏定义 (K230.h)

```c
#define BEAN_GREEN   0x06   /* 绿豆 */
#define BEAN_YUN     0x07   /* 芸豆 */
#define BEAN_YELLOW  0x08   /* 黄豆 */
```

### 典型调用流程

```c
// Phase 1: K230 自动启动，STM32 等待 bean_flag
while (!bean_flag) osDelay(10);
// bean_color[0..2] 已就绪
bean_locked = 0;  // 解锁
k230_write(K230_CMD_CLOSE);  // 发送应答

// Phase 2: 移动到位置后
k230_write(K230_CMD_LOOK_NUMBER);  // 0x03
while (!front_number_flag) osDelay(10);
// front_number[0..2] 已就绪
k230_write(K230_CMD_CLOSE);  // 发送应答

// Phase 3: 移动到新位置后
k230_write(K230_CMD_LOOK_SIDE);  // 0x01
while (!full_number_flag) osDelay(10);
// number_position[0..4] 已就绪
k230_write(K230_CMD_CLOSE);  // 发送应答

// 使用 Data_Handle1() 根据豆子颜色查找位置
Data_Handle1(BEAN_GREEN);   // 绿豆 -> 查位置 -> Action_x
Data_Handle1(BEAN_YUN);     // 芸豆
Data_Handle1(BEAN_YELLOW);  // 黄豆
```
